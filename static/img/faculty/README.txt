Drop a real photo for a teacher in this folder, named EXACTLY to match their
slug (the last part of their profile URL), for example:

  kabita-das.jpg          -> shows on Kabita Das's profile automatically
  chandramuhan-hazarika.jpg

Accepted formats: .jpg, .jpeg, .png, .webp
No code changes needed — the website checks this folder automatically and
uses the initials avatar as a fallback for anyone without a photo here.

To find a teacher's exact slug, visit /faculty on the site and check the
URL when you click their name (e.g. /faculty/kabita-das -> slug is
"kabita-das").
